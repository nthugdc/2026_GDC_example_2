# 第 2 章 · Rule Tile 與動畫磁磚（30 分鐘）

場景：`Assets/_GDC/Scenes/Ch2_RuleTile.unity`　　**這一章不用寫程式，但要改資產。**

---

## 磁磚也是「資產」

`Assets/_GDC/Tiles/` 裡的每個檔案都是一種磁磚。改了資產，**所有用到它的地方都會一起變** —— 不管畫了 1 格還是 1000 格。

這一章有三種磁磚：

| 種類 | 圖示 | 特色 |
|---|---|---|
| **Tile** | 石磚、紅磚 | 一個印章一個圖案 |
| **Animated Tile** | 岩漿 | 一個印章，好幾張圖輪流播放 |
| **Rule Tile** | 草地 | 一個印章，**依照旁邊有沒有同伴**自動換圖 |

---

## 任務一：讓岩漿動起來

1. Project 視窗選 `Assets/_GDC/Tiles/Lava_Ch2`
2. Inspector 的 **Min Speed** 和 **Max Speed** 都是 `0`，改成 `4`
3. 按播放，岩漿開始流動了

| Speed | 結果 |
|---|---|
| `0` | 停住 |
| `1` | 慢慢冒泡 |
| `4` | 正常 |
| `20` | 閃到眼睛痛 |

> 伏筆：這就是**逐格動畫**的原理 —— 第 4 章的角色走路也是一樣的東西。

## 任務二：用 Rule Tile 畫踏腳石

岩漿池太寬跳不過去。

1. Tile Palette 選 **Palette_Ch2**，Active Tilemap 選 **Ground**
2. 選左上角的草地（`Ground_Ch2`），在岩漿上方畫幾塊踏腳石
3. 注意看：**你只選了一種磁磚，但上面自動長出草皮**

> 角色一次大約跳 4 格遠，踏腳石之間別隔太開。

## 任務三：幫 Rule Tile 補規則

仔細看你畫的踏腳石和那根小柱子：**頂端有草、左右兩側卻沒有黑框**。因為這個 Rule Tile 只寫了「頂端」的規則。

1. Project 選 `Assets/_GDC/Tiles/Ground_Ch2`
2. Inspector 的 **Tiling Rules** 可以看到四條規則，每條旁邊有個 3×3 小方格
   - 綠色箭頭 = 那個方向**有**同一種磁磚
   - 紅色 X = 那個方向**沒有**同一種磁磚
   - 空白 = 不管
3. 按清單下方的 **+** 新增一條規則：
   - 點小方格的**左邊**那格，直到變成**紅色 X**
   - 右邊的 Sprite 欄位拖入 `Assets/_GDC/Art/Tiles/Ground_L`
4. 再新增一條，**右邊**設紅色 X，Sprite 用 `Ground_R`

改完不用重畫，場景裡的草地會**自動**更新。

### 規則的順序很重要

規則**由上往下**比對，**第一條符合的就用它**。所以條件越多的規則要放越上面。

加分題：一格寬的柱子「左右都沒有同伴」，現在只會套到其中一邊的框。
再加一條「左右都是紅色 X」、用 `Ground_LR` 的規則，**把它拖到 L、R 規則的上面**。

## 任務四：圖層的前後

走到樹叢那裡：角色會走到樹叢**後面**。樹叢在 `Foreground` 這層，它的 Order in Layer 是 `20`，比角色的 `10` 大。

| 圖層 | Order in Layer |
|---|---|
| Background（背景牆） | -20 |
| Ground（地面） | 0 |
| Hazard（岩漿） | 1 |
| Decor（小草） | 2 |
| 角色 | 10 |
| Foreground（樹叢） | 20 |

## 常見問題

**Q：岩漿那層也有碰撞，為什麼不會站在上面？**
A：Hazard 那層的 Composite Collider 2D 勾了 **Is Trigger**：只偵測「碰到了」、不會擋住。碰到就交給 `KillZone` 腳本送回起點。

**Q：新增的規則沒效果？**
A：檢查 Sprite 欄位有沒有放圖，以及小方格是不是點成紅色 X（不是綠色箭頭）。
