## 兩種座標

| | 型別 | 例子 | 誰在用 |
|---|---|---|---|
| **世界座標** | `Vector3` | `(3.7, 0.2, 0)` | 角色、攝影機、所有一般物件 |
| **格子座標** | `Vector3Int` | `(3, 0, 0)` | Tilemap 的每一格 |

Tilemap 只聽得懂格子座標。想知道「角色腳下是什麼」，流程永遠是：

```
角色的世界座標  →（WorldToCell）→  格子座標  →（GetTile）→  磁磚資產
```

磁磚資產可以直接用 `==` 跟你在 Inspector 指定的 `iceTile`、`lavaTile` 比較。

## 四個函式

| 函式 | 做什麼 |
|---|---|
| `WorldToCell(世界座標)` | 這個位置在哪一格 |
| `GetTile(格子)` | 這格放了什麼磁磚（空的就是 `null`） |
| `SetTile(格子, 磁磚)` | 在這格放磁磚；傳 `null` 就是挖掉 |
| `HasTile(格子)` | 這格有沒有東西 |

詳細的參數說明寫在腳本最上方，寫程式時翻那裡。

### 一定要親手試的錯誤

**3-D 的 z 陷阱**：先**不要**把 z 歸零，直接拿 `ScreenToWorldPoint` 的結果去算格子，然後 `Debug.Log` 印出來 ——
你會看到 z 是 `-10` 左右。拿這個去 `GetTile`，永遠只會拿到 `null`，怎麼點都挖不動。

**3-B 只寫一半**：只寫「是冰就變滑」，不寫「不是冰就變回來」。離開冰面之後，角色會一直滑下去。

**挖自己腳下**：站在磚上把腳下那塊挖掉。碰撞是即時更新的 —— 你會掉下去。

## 常見問題

**Q：Console 一直出現紅字 NullReferenceException？**
A：點兩下紅字會跳到出錯的那一行。通常是 Inspector 上某個欄位沒指定，或是變數名稱打錯。

**Q：挖不動？**
A：先 `Debug.Log` 印出 `mouseCell` 和那格的 `GetTile` 結果。格子座標看起來怪怪的，八成是 z 沒歸零。

**Q：分數就是磚塊數？**
A：對，HUD 只會顯示「分數」，所以這章借用它來記你手上有幾塊磚。
