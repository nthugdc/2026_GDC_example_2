# 第 0 章 · 認識 Grid 與 Tilemap（15 分鐘）

場景：`Assets/_GDC/Scenes/Ch0_Grid.unity`　　**這一章不用寫程式。**

---

## Tilemap 是什麼

想像一張**方格紙**。你不用一塊一塊擺方塊，而是拿印章在格子上蓋 —— 蓋到哪，哪裡就有一塊地。

Unity 用三個東西做到這件事：

| 東西 | 比喻 | 在 Hierarchy 的哪裡 |
|---|---|---|
| **Grid** | 方格紙本身，決定每一格多大 | 最上層的 `Grid` |
| **Tilemap** | 一張透明的描圖紙，疊在方格紙上 | `Grid` 底下的 `Background`、`Ground`… |
| **Tile** | 印章，蓋下去就是一格圖案 | `Assets/_GDC/Tiles/` |

一個 Grid 底下可以有**很多層** Tilemap：背景一層、地面一層、裝飾一層。
分層的好處是：可以只讓「地面」那層有碰撞、只讓「裝飾」那層畫在角色前面。

---

## 任務一：地面不見了

一按播放，角色明明站著，腳下卻什麼都沒有。地面其實在那裡，只是被**背景蓋住了**。

1. 按**停止**
2. Hierarchy 選 `Grid` 底下的 `Ground`
3. 找到 **Tilemap Renderer** 元件的 **Order in Layer**，現在是 `-30`
4. 背景（`Background`）是 `-20`。**數字越大畫在越前面**，把 Ground 改成 `0`

> 想一想：為什麼角色沒有掉下去？
> 因為**畫面**和**碰撞**是兩件獨立的事。Tilemap Renderer 負責畫，Tilemap Collider 2D 負責碰撞。

## 任務二：看不見的橋

中間有個坑過不去。`Bridge` 這層其實已經畫好一座橋，但它**透明**而且**沒有碰撞**。

1. 選 `Grid` 底下的 `Bridge`
2. **Tilemap** 元件的 **Color**：點開色盤，把 **A**（透明度）拉到 `255`
3. **Tilemap Collider 2D** 元件：勾選左上角的方框啟用它

只做第 2 步：看得到橋，但人會穿過去。只做第 3 步：看不到橋，但走得過去。兩個都試一次！

## 加分實驗：Cell Size

選 `Grid`，把 **Cell Size** 從 `1, 1, 0` 改成 `0.5, 0.5, 0`，按播放看看。

| Cell Size | 結果 |
|---|---|
| `1, 1` | 正常 |
| `0.5, 0.5` | 整張地圖縮成一半，但磁磚圖案不會跟著縮 → 重疊在一起，角色變巨人 |
| `2, 2` | 地圖放大一倍，磁磚之間出現縫隙 |

看完**記得改回 `1, 1, 0`**。

## 常見問題

**Q：我改了數字但沒反應？**
A：是不是在播放中改的？停止之後會還原，要先停止再改。

**Q：Color 的 A 拉不動？**
A：點色塊打開色盤，下面有 R G B A 四條，A 在最下面。
